🎓 AI Test Generator - Sozlash Qo'llanmasi

⚠️ Muhim: Bu ilovani ishlatish uchun Google Client ID va AI API kalitini sozlash kerak!

1. Google Sign-In Sozlash

1.1. Google Cloud Console ga kiring

Google Cloud Console

1.2. Yangi loyiha yarating

Agar loyihangiz yo'q bo'lsa, yangi loyiha yarating yoki mavjudini tanlang.

1.3. OAuth 2.0 Client ID yarating

  1. "APIs & Services" > "Credentials" ga o'ting
  2. "Create Credentials" > "OAuth 2.0 Client IDs" ni bosing
  3. Application type: "Web application" ni tanlang
  4. Name: "AI Test Generator" deb nomlang
  5. Authorized JavaScript origins qo'shing:
    http://localhost:3000
    https://yourdomain.com
  6. "Create" ni bosing va Client ID ni nusxalang

2. Konfiguratsiya Faylini Sozlash

2.1. config.js faylini oching

Loyiha papkasidagi config.js faylini matn muharririda oching.

2.2. Google Client ID ni kiriting

Quyidagi qatorni toping va o'z Client ID ingizni kiriting:

CLIENT_ID: 'YOUR_GOOGLE_CLIENT_ID', // Bu yerga o'z Client ID ingizni kiriting

2.3. AI API kalitini kiriting (ixtiyoriy)

Agar AI savollar yaratmoqchi bo'lsangiz:

API_KEY: 'YOUR_AI_API_KEY', // OpenAI, Gemini yoki boshqa AI API kaliti

3. AI API Sozlash (Ixtiyoriy)

3.1. OpenAI API

OpenAI API Keys

Yangi API kalit yarating va config.js ga kiriting.

3.2. Google Gemini API

Google AI Studio

Gemini API kalitini yarating.

Eslatma: AI API sozlanmasa, ilova oldindan tayyorlangan savollarni ishlatadi.

4. Ilovani Ishga Tushirish

4.1. HTTP Server ishga tushiring

Terminal/Command Prompt da loyiha papkasiga o'ting va quyidagi buyruqlardan birini bajaring:

# Python bilan python -m http.server 3000 # Node.js bilan npx http-server -p 3000 # PHP bilan php -S localhost:3000

4.2. Brauzerda oching

http://localhost:3000

6. Muammolarni Hal Qilish

Google Sign-In ishlamayapti

  • Client ID to'g'ri kiritilganini tekshiring
  • Domain authorized origins ro'yxatida ekanini tekshiring

Savollar yaratilmayapti

  • AI API kaliti to'g'ri ekanini tekshiring

  • Fallback savollar ishlatilayotganini tekshiring

  • Browser console da xatolarni ko'ring
